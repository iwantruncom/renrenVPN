# Device icons

The four device icons are derived from Google Material Design Icons
(`laptop_mac`, `phone_iphone`, `phone_android`, and `desktop_windows`), outlined style,
at commit `737e3324305806514d7909874fa1818ae1808232`.

Source: https://github.com/google/material-design-icons
License: Apache License 2.0 (see `LICENSE` in this directory).

The SVG root fill color was changed to match the RenrenVPN interface. These
icons identify device categories; they are not Apple, Android, or Microsoft
endorsement marks.
